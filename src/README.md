# ♟ Chess Scout & Trainer Telegram Bot (Тренажер + PNG-Паспорт + БД + Админка)

Готовый коммерческий Telegram-бот для анализа шахматных партий на **Chess.com** и **Lichess.org**:
- **Тренажер дебютных ловушек** (`trainer.py`) — отдельная кнопка «🧩 Тренировать эти ловушки», рисует шахматную доску (PNG) с критической позицией и предлагает выбрать правильный ход с объяснением тренера.
- **Генератор PNG-карточек «Шахматный Паспорт»** (`card_generator.py` на базе `Pillow`).
- **Безлимитный бесплатный режим для Админа** (включается автоматически по команде `/admin`).
- **База данных SQLite** (`database.py`), **Реферальная система (+2 разбора за друга)** и оплата **Telegram Stars (XTR)**.

## Быстрый старт в PyCharm
1. Установи зависимости (включая `pillow` для рисования доски и карточек):
   ```bash
   pip install -r requirements.txt
   ```
2. Запусти `main.py` или `bot.py`.
